# Mi-primera-app-Android
# Recetas de mi Tierra

## Descripción

**Recetas de mi Tierra** es una aplicación Android dedicada a las recetas tradicionales de Andalucía. Su objetivo es mostrar las recetas de forma sencilla y ordenada, con información sobre los ingredientes y el tiempo de preparación.

La aplicación tiene una interfaz adaptada a dispositivos Android y recursos organizados para mostrar los textos en español e inglés.

## Tecnologías utilizadas

- Android Studio.
- Java.
- Recursos Android: textos, imágenes, colores, estilos e icono.

## Cómo ejecutar la aplicación

1. Descargar o clonar este repositorio.
2. Abrir el proyecto con Android Studio.
3. Esperar a que termine la sincronización de Gradle.
4. Seleccionar un dispositivo virtual Android.
5. Pulsar el botón **Run ▶** para ejecutar la aplicación.

## Estructura del proyecto

- `app/`: contiene el proyecto Android.
- `app/src/main/java/`: contiene el código Java.
- `app/src/main/res/layout/`: contiene los diseños XML de las pantallas.
- `app/src/main/res/drawable/`: contiene las imágenes.
- `app/src/main/res/values/`: contiene los textos, colores, medidas, estilos y tema.
- `app/src/main/res/values-en/`: contiene los textos en inglés.
- `docs/`: contiene la documentación de la práctica.
